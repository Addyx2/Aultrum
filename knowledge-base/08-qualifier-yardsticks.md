# 08 · The Qualifier Yardstick Table — what the qualifier grades

> Master reference: every layer, its yardsticks, what the qualifier computes, and the judgement it produces for the package.

---

## Six lenses, one judgement

**Judgement:** *Is quality care being delivered — and is it consistent?*

| Lens | Qualifier grades | Package health signal |
|------|------------------|----------------------|
| **Competence** | Training currency, cert status, skill-match, skill decay | Can the package demonstrate skill? |
| **Compliance** | Record completeness, safeguarding, audit risk | Would the package pass inspection today? |
| **Shift Readiness** | Rest adequacy, shift load, fatigue, reliability | Is the package fit for the next shifts? |
| **Rapport** | Continuity, satisfaction trend, bond score | Is the relationship trusted and consistent? |
| **Satisfaction** | Response, level, trend, voice access | Does the receiver experience quality? |
| **Purpose** | Tenure, growth, recognition, burnout adjust | Will the carers stay? |

---

## The graded table

| Layer | Yardsticks (L1/L2) | Qualifier output | Recommendation it enables |
|-------|-------------------|------------------|---------------------------|
| **Competence** | Training currency · cert status · skill-match · skill decay · verification gap | Competence score + team gap list | "Carer A is 3 trainings behind — schedule training." |
| **Compliance** | Registration · record completeness · safeguarding · training· DBS | Compliance score + audit risk | "Close medication log gap within 72h." |
| **Shift Readiness** | Rest · shift load · fatigue proxy · preparedness · reliability | Readiness forecast (next K shifts) | "Carer B not ready for next 3 — rotate to C, D." |
| **Rapport** | Continuity · satisfaction trend · interaction · incidents | Bond score per pair + package rapport | "Preserve core team for next block." |
| **Satisfaction** | Response · level · trend · voice · complaints | Satisfaction score + trend | "Trend climbing — healthy; keep feedback loop open." |
| **Purpose** | Tenure · attendance · recognition · growth · relationship | Purpose score = consistency predictor | "Address carer B load to protect tenure." |

---

## How the qualifier uses the table

```
1. COLLECT    → L1 signals from ordinary care data (rota, clock-in, training,
                praise, satisfaction, complaints)
2. GRADE      → mathematical model per lens → L2 measures (scores)
3. SYNTHESIZE → weighted cross-lens read → L3 package health judgement
4. RECOMMEND  → actions per lens, ranked by severity × likelihood
5. ATTRIBUTE  → same observations flow down to each individual's profile
                (carer sees "fatigue flag"; coordinator sees package-level health)
6. LEARN      → persona intelligence corrects weights from observed outcomes
```

---

## Weighting principles

- **Temporal weighting:** age matters — an obligation unresolved for 9 days weighs more than one opened today (Compliance); a fatigue streak of 3 weeks weighs more than a single long week (Readiness).
- **Trend over level:** climbing satisfaction beats static satisfaction (Satisfaction); declining readiness is louder than low readiness (Readiness).
- **Basis-justified weights:** every weight traces to a legal or psychological framework (Yardstick anatomy, page 01).
- **Persona-corrected:** population priors, individual posteriors — the more a package is observed, the more its own limits are trusted.

---

## Grading levels (qualifier output vocabulary)

| Grade | Meaning | Typical action |
|-------|---------|----------------|
| 0.85+ | Healthy and consistent | Maintain; no intervention |
| 0.70–0.84 | Adequate but watchable | Monitor; one recommendation |
| 0.55–0.69 | Declining / at risk | Active intervention recommended |
| <0.55 | Unhealthy | Priority review; escalate to coordinator |

Grades are computed **per lens** and **per package**, then attributed to individuals — a package never hides an underperforming carer, and a carer never hides in a healthy package.
